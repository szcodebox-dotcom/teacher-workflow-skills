# 学情分析 · 技能包摘要

**技能 ID：** `teacher-learning-insights` · **版本：** 2.0.0

**解决的问题：** 把脱敏小题成绩转为可复核的知识点表现和复测证据，避免空分当零分、分母混用与跨卷误比较。

| 项目 | 内容 |
|---|---|
| 触发 | 分析成绩、查看知识点表现、核对多次测验变化 |
| 必要输入 | 六列 CSV：exam_id、student_id、question_id、knowledge_point、score、max_score |
| 产物 | JSON 数值报告、Markdown 阅读报告、需要时补充教学跟进表 |
| 运行环境 | Python 3.9+；脚本仅用标准库，无网络与第三方依赖 |
| 核心口径 | 空分不计有效分母；零分有效；整卷统计仅完整评分学生；知识点按有效满分加权 |
| 限制 | 得分不证明错因；缺少题目行的全班学生无法统计；归一化不等于试卷难度等值 |
| 包内资源 | 数据口径、完整合成例子、可运行 CSV、分析脚本、界面调用配置 |

**即用提示词：** 使用 `$teacher-learning-insights` 分析我提供的脱敏小题成绩，交付分母可核对的报告，并写出缺失数据限制和复测建议。

**验证状态：** 包内例子与测试为合成数据计算验证，未宣称真实班级教学实测。
