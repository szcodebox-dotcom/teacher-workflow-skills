# 成绩数据契约与指标定义

## 长表字段

CSV 使用 UTF-8 或 UTF-8 BOM。每行是某次测验某位学生某道题的一次评分记录。允许额外列，但不参与计算；额外无列名字段报错。

| 列 | 要求 |
|---|---|
| exam_id | 非空测验代号；时间顺序另由教师说明，脚本按代号排序不声称先后 |
| student_id | 非空脱敏标识；同一学生在同一卷应始终使用同一标识 |
| question_id | 非空题号；可为小题，如 Q2b |
| knowledge_point | 非空、每题一个主要知识点；同一卷同题的标签必须一致 |
| score | 有限数值，0 ≤ score ≤ max_score；空白表示缺少评分记录 |
| max_score | 有限正数；同一卷同题的满分必须一致 |

同一 `(exam_id,student_id,question_id)` 不能出现两次，即使一条为空分也报错。重复不得按最后一行覆盖。同一卷的可见题目集合来自该卷所有行；可见学生集合同理。完全没有行的题目或学生无法发现；若已有正式名单和试卷题目表，应先核对再运行。

一个题目只带一个主要知识点，避免重复计分。多知识点试题如需拆分，应先由教师给出小题及其评分点，使用互不重叠的得分和满分拆成多行，不能把整题分值复制给每个知识点。

## 缺失与完整度

- **完整记录学生：** 可见题目集合的每一题都有非空分数。
- **部分记录学生：** 至少一题有分数，但未覆盖全部题目；空分和完全缺行的题目都计入未评分题数。
- **全未评分学生：** 可见名单内没有任何有效分数。只能报告“全未评分”，不得断言缺考，因为空分也可能是尚未录入。
- **评分覆盖：** 有评分记录的满分 / 可见试卷满分。比如 10 分卷已评分 6 分，覆盖为 60%。部分学生的得分率仅描述已评分部分，不能充当整卷得分率。
- 若文件为空或全文件没有一个有效评分，脚本退出码为 2，不生成报告。有效的零分能够产生报告。

## 计算

知识点 `K` 的有效得分率：`sum(该卷K已评分小题得分) / sum(该卷K已评分小题满分)`。不同满分小题按满分自然加权；不先算每题百分比再平均。报告同时包含有效作答条数、参与有效评分的学生数、累计分子和分母。

题目得分率沿用同一累计口径；失分率为 `1 − 得分率`。它不同于答错人数比例。另报告满分作答比例与零分作答比例，两者均以该题有效作答人数为分母。部分得分的题目不自动归为“错题”。

整卷平均分、整卷平均得分率、通过/优秀率、最高与最低分只对完整记录学生计算。完整学生为零时这些字段为 JSON `null`，阅读报告写“无完整记录，未计算”。通过/优秀阈值按整卷得分率判断，且边界包含等号；默认分别为 0.60、0.85。可用 `--pass-threshold` 与 `--excellent-threshold` 设置，须满足 `0 ≤ 通过 ≤ 优秀 ≤ 1`。

整卷“已评分作答加权得分率”纳入部分学生的已评分题，用于展示有效数据总体口径；它不是学生平均分，也不是全班平均得分率。JSON 分开储存这些指标，不能混称。

## 多卷与输出

每卷独立报告其可见满分、完整/部分/全未评分人数、知识点与题目指标。不因满分相同就推定等值；满分不同的原始总分不直接比较。

`--aligned-exams` 只允许生成共同知识点的描述性百分点差，差值按 **exam_id 字典序** 中相邻且该知识点有有效评分的测验计算。输出明确展示两卷代号，调用者应按实际日期解释；需要固定时间顺序时使用按时间可排序的代号。未经显式对齐声明时 `comparisons.knowledge_points` 为空。

JSON 指标小数保留六位，Markdown 百分比展示两位；计算内部使用十进制定点数，差值依据未四舍五入的分子分母计算。输出文件为 `report.json` 和 `report.md`，不含排名与错因结论。
