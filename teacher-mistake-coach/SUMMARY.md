# 错题订正技能包摘要

**能力**：从原题与实际作答证据出发，完成识别、归类、订正、原创练习和复测跟进。

| 项目 | 内容 |
|---|---|
| 输入 | 题目照片或原文、学生作答、错题定位；可选参考答案 |
| 输出 | 证据总览、学生订正与巩固单、教师答案评分、复测题与判定规则 |
| 核心区分 | 可见错误是事实；为什么错误是待验证假设；未测结果不可写成进步 |
| 资源 | 一个合成错题案例、两道完整巩固题、两道完整复测题与全部评分 |
| 环境 | 可读取图片或文本的助手；OCR 无法确定时列待补并处理清晰部分 |
| 边界 | 不猜读模糊字符、不固定贴标签、不自动联系学生或创建提醒 |

**调用示例**：使用 `$teacher-mistake-coach`，整理照片中已圈出的方程错题，保留识别依据，给正确解法、两道原创巩固题和下一次课用的复测及评分。

**闭环**：可核验原题与作答 → 错误事实/错因假设 → 正确解法 → 实际巩固题 → 独立复测 → 达标回看或针对证据再练。

**验收**：每个可用条目有完整题干与订正；每道练习有答案与分值；复测标准可执行；未发生结果记为未测；缺失证据与可用条目分开。
