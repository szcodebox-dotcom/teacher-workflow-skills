# 班级跟进

把测验证据落实到“下一节怎样教、两周内怎样验证”。不把学生分数变成固定群体名称，也不从得分率直接推断错因。

## 输入判定

需要年级学科、教学范围、可用课时及测验题目/评分规则。证据可为脱敏小题成绩、已有统计报告、匿名作答或课堂观察。可用课时未知时可先给出相对日程，并标出每次占用分钟；没有题面时只完成数据与安排层面的工作，不编造题目所考内容。

先核对报告的有效人数、满分、空分、统计分母与可比性。若有原始长表，可使用 `$teacher-learning-insights`；未安装时根据明确口径手工计算并展示分子分母，不声称已调用。总分表只能支持总分层面的描述，不能生成某道题的错因或知识点结果。

必要输入缺失时一次说明影响决策的缺项，同时完成能独立完成的部分。班级真实证据与用于展示的合成案例分开标注。

## 形成行动

1. **确定教学优先项。** 从课程目标、有效失分和评分覆盖中选择最影响后续学习的项目。题目失分率不等于答错人数比例；保留有效人数与缺失人数。只有评分数据时写待验证问题，拿到作答后再定位失分步骤。
2. **组织讲评。** 每项写清目标、所用证据、课堂任务、时间、检测方式。先让学生展示或重做关键步骤，再根据评分点讨论；避免整节逐题念答案。
3. **提供弹性练习。** 按当前任务表现安排不同练习入口，例如前置步骤、完整任务、迁移任务。每个入口都写进入条件、完成标准与切换条件；学生可自选并根据当天证据流动，不用“优/中/差”等固定人群标签。
4. **排两周跟进。** 把讲评后的短检测、间隔复测和调整放在 Day 1–14。每次明确责任人、用时、题目/评分标准、收集结果及触发下一步的条件。用户给了真实日期再换成日期；不要假设节假日或学校课表。
5. **检查复测可比性。** 复测使用相同目标与评分点、不同表述或数值的任务。样本和题目不同只能描述，不能把总分变化作为干预效果证据。对缺评分学生安排补录或补测，以实际情况决定，不把他们算作未掌握。

## 交付契约

交付一套能执行的材料：

- 证据表：目标/题目、有效得分与满分、人数、缺失、已知事实、待验证问题。
- 讲评安排：环节、分钟、教师与学生动作、当堂检测、调整条件。
- 弹性练习：题面或任务说明、答案、逐点评分、进入/切换条件。
- 两周跟进表：窗口、责任人、任务、产物、检查标准、未达到标准时的下一步。
- 复测记录格式：脱敏标识、题号、各评分点、总分、是否完整、观察到的操作证据。

所有比例注明分母；分母不足时写“仅作为核对线索”，不给看似精确的全班诊断。完整范例见 [合成教学例子](references/worked-example.md)。沟通稿需转交时，提供聚合结果、限制和行动进展，不附学生排名表。
