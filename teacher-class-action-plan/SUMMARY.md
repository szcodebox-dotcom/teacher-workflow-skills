# 班级跟进 · 技能包摘要

**技能 ID：** `teacher-class-action-plan` · **版本：** 2.0.0

**解决的问题：** 成绩讲评结束后仍缺少练习选择、复测节奏和调整条件，难以验证学生是否完成目标步骤。

| 项目 | 内容 |
|---|---|
| 触发 | 本班下一步怎么教、安排讲评与复测、把学情报告转为教学行动 |
| 输入 | 脱敏证据、题面/评分规则、年级学科、可用课时 |
| 输出 | 证据表、讲评计划、含答案评分的弹性练习、两周安排、复测记录表 |
| 核心区分 | 得分表现与错因证据分开；练习入口可以流动；缺分不等于未掌握 |
| 可选协作 | 有原始小题成绩时先做学情分析；发布聚合沟通稿时交给教学沟通 |
| 独立使用 | 不依赖其他技能安装；已有有效报告即可直接使用 |
| 验证状态 | 包内完整例子为合成教学设计，未宣称课堂效果验证 |

**即用提示词：** 使用 `$teacher-class-action-plan` 把这份学情报告和试卷转成能直接执行的讲评、弹性练习与两周复测计划，注明证据和调整条件。
