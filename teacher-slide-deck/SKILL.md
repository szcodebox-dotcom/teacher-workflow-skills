# 可编辑课件

交付可实际打开和修改的课件。用户授权做 PPT 后就完成 PPT；大纲是内部组织步骤，只有用户要求先审大纲时才等待大纲反馈。

## 输入与课堂设计

最低输入是年级或学段、学科、课题，或一份足够完整的教学内容。可选输入为教案、教材页、课时、页数、用途、屏幕比例和视觉偏好。

课题歧义会改变课程内容时集中澄清。其他缺项使用明示默认：一课时 40 分钟、16:9、以大字与原创图形为主。没有教材正文时写原创教学例题，不冒称教材原题；没有课堂数据时不编造正确率。

1. 把内容按“提出任务—示范或探究—练习—独立检测—课后反馈”形成学习路线，页数以用户要求为准。
2. 每页确定一个教学动作：讲什么、学生做什么、怎样收束。练习页显示完整题干和数据；答案放讲者备注或后续讲评页，避免在检测前曝光。
3. 图表用可编辑表格或形状表达核心信息。使用图片时保留来源和许可依据；没有合适图片也能用原创图形完成，不用素材占位符。
4. 为每页写讲者备注：建议时长、追问、答案或观察点。预计总时长与课时一致；时长是建议，不是实际课堂记录。

## 生成 PPTX

本包自带独立生成器，适合 16:9 简洁中文课件，支持可编辑标题、双栏内容、单栏内容和数据表格。读取 [内容结构](references/deck-schema.md) 后编写完整 JSON，或从 [示例数据](references/example-deck.json) 理解格式。

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python scripts/build_deck.py references/example-deck.json --output lesson.pptx
```

命令从技能目录运行；输入输出也可用绝对路径。安装到当前项目虚拟环境，不需要全局修改。已有 Python 与 python-pptx 时可直接使用已有运行时。缺少依赖且无法安装时交付完整 JSON 与逐页内容，并明确 PPTX 尚未生成；不能给一个未存在的成品链接。

该生成器限定简洁布局，不处理动画、复杂公式、嵌入视频或任意版式。此类要求用当前可用的专门课件工具完成并检验，或如实说明缺项；不把未实现功能写成已完成。

## 验证与交付

- 重新打开 PPTX，核对页数、顺序、标题、表格值及备注。生成器输出成功只确认结构，不证明页面无溢出。
- 有本地渲染工具时渲染全部页，至少检查封面、最长内容、数据表、检测、作业页的文字范围、字号、对比和元素遮挡；发现问题先修复。
- 无渲染工具时做结构检查，并明示视觉预览未验证。中文字体是否可用取决于打开课件的环境，交付推荐字体和替代建议。
- 交付实际 PPTX、完整 JSON、逐页内容或备注摘要与一段使用说明；只报告实做检查。用户只要大纲时无需生成多余 PPTX。
