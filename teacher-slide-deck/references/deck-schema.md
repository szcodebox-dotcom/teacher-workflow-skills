# 独立生成器内容结构

输入为 UTF-8 JSON 对象。示例见 [example-deck.json](example-deck.json)。

| 字段 | 要求 |
|---|---|
| `title` | 完整课题，非空字符串，最多 80 字符 |
| `audience` | 年级、学科与用途，最多 70 字符 |
| `font` | 可选字体名，默认 Microsoft YaHei；打开环境可能替代为本地字体 |
| `total_minutes` | 可选正数；提供后必须与各页分钟数合计一致 |
| `slides` | 1–60 页，每页一个对象 |

所有页面均需 `kind`、`title`、`minutes`、`notes`；标题最多 34 字符，分钟数是大于 0 且不大于 120 的数值，备注必须是非空完整文本。可选 `takeaway` 最多 54 字符，显示在页底。

- `kind: "title"`：另需 `subtitle`，最多 100 字符。
- `kind: "content"`：另需 `panels`，包含一或两个对象。每个对象有 `heading`（最多 24 字符）与 `lines`（1–5 条，每条最多 64 字符，每栏合计不超过 140 字符）。
- `kind: "table"`：另需 `headers`（2–5 列，单格最多 14 字符）与 `rows`（1–6 行）；每行列数与表头一致，单格为完整字符串、最多 24 字符。数值也写成字符串，保留单位。

在字符上限之外，生成器根据单栏或双栏实际宽度、字号、段间距和表格行高估算换行；标题、副标题、栏标题、页底要点、正文和表格内容估算超出各自框时拒绝生成，要求拆页或缩短内容。时间必须是有限正数，不接受 NaN 或无穷值。换行估算不能替代渲染检查。复杂公式、视频与动画不在此生成器范围内。检测答案写入 `notes`，除非该页就是讲评页。`minutes` 与 `notes` 都写入 PowerPoint 讲者备注。
