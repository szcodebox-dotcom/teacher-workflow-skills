# 有据题库

把已存在的材料变成可追溯题库；“历史真题”需要可核验的考试出处，不能靠看似真实的年份、地名或学校名包装新题。

## 来源与可用范围

先建立材料台账：材料 ID、文件名或链接、发布者、页码/原题号、许可依据、允许用途、核验状态。用户上传材料可支持按其要求进行个人或课堂内处理，但不能据此推定可在公开仓库、公众号或开放题库发布全文。第三方材料许可不清时继续做目录、定位和内容摘要；需要公开全文时明确取得适用许可，或改为独立原创教学题。

检索网络材料时使用可获得的来源工具并实际读取；没有联网或原件时只处理已有输入，不编造检索结果。网站营销标签不能独立证明它是某年的正式原题。需要官方真题时核验官方发布或可交叉核对的原件，并区分“已核验”“来源声明未核验”“原创/改编”。

## 抽取与筛选

1. 按年级、学科、范围、题型、数量和用途筛选已有材料。每条记录保留稳定题目 ID 与材料定位，题号和年份从原件读取。
2. 提取完整题干、选项、图表、单位和小问。图片识别后逐项对照原图；不清楚的字、指数、分数线或图形标注保留明确缺失位置，标为“待补原件”。不得根据预想答案倒推模糊题干。图表不可读时不交付为可用题。
3. 答案与题干分开抽取，保留答案页定位。没有答案时写“原答案缺失”；不得猜填官方答案。若题干完整且用户需要独立求解，可生成明确标为“独立推导解”的解答，并展示核验过程；它不替代不存在的官方答案。官方答案与独立解冲突时记录两者和冲突证据，暂不列入已核验可用题。
4. 保留原题与衍生版本的关系。更改条件、数据或题干后生成新 ID，标注“原创变式”或“改编”，不沿用原题真实性标签。客观题唯一性和主观题评分均须独立核验；原材料没有分值时，组卷使用的分值是本次分配，不说是原卷分值。
5. 输出筛选结果与排除理由。用户指定先选题时交付候选并等待选择；已经授权按条件自动筛选时直接筛选和成卷，不默认增设确认关卡。
6. 有组卷请求时检查题分、评分分项、考试总分和覆盖，把学生卷与答案卷分开。候选不足要明确实际数量及缺口；不能凭空补出“真题”。公开交付只含确有公开许可的正文、本次独立原创内容，或来源定位与摘要。

## 题库记录

每条至少包含：`item_id`、学段/学科、知识点、题型、题干或受限摘要、材料 ID、页码/原题号、原题真实性状态、许可范围、OCR/转录状态、答案内容及来源状态、原始分值或本次分配分值、可用状态。将不完整或冲突条目放入待处理表；不混进“可直接使用”题库。

交付材料台账、题库、排除/待核验记录；成卷时加答案与可加总评分和来源索引。无需公开真实学生信息。完整本包原创授权材料及抽取案例见 [worked-example.md](references/worked-example.md)；该案例明确为合成材料，不冒充真实历史考试。
