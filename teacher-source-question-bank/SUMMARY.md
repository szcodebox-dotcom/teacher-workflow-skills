# 有据题库技能包摘要

**能力**：整理已有获授权材料，保留题干与答案的来源证据，按条件筛选并可进一步成卷。

| 项目 | 内容 |
|---|---|
| 输入 | 原件、可实际读取的链接或图片；筛选条件与用途 |
| 输出 | 材料台账、结构化题库、来源索引、待核验表；可选学生卷与评分卷 |
| 核心证据 | 发布者、原页码/题号、真实性状态、使用范围、转录核验和答案定位 |
| 环境 | 能读取输入文件的助手；联网检索仅在有实际来源工具时使用 |
| 示例 | 本包原创合成材料，完整题目、答案、分值与抽取记录 |
| 权限边界 | 课堂内处理权限不自动覆盖公开发布；许可不清时只给摘要与来源定位 |

**调用示例**：使用 `$teacher-source-question-bank`，从我上传的获授权课堂资料中抽取七年级方程题，保留原页码、答案页与原分值，缺失或模糊内容单列，不补造真题。

**闭环**：材料与用途核验 → 完整抽取 → 原答案定位 → 条件筛选 → 可用/待核验分开 → 来源可追溯交付。

**验收**：每道可用题能回到原件；真题标签有核验依据；OCR 不确定项未被猜填；派生解与原答案分开；公开内容符合已知许可范围。
