# 细目表组卷技能包摘要

**能力**：用考试蓝图控制知识点与能力覆盖，让每一分能够对应到细目格。

| 项目 | 内容 |
|---|---|
| 适用任务 | 按细目表组卷、检查必考目标、控制题型和分值比例 |
| 输入 | 范围、总分、时长、细目表；可选获授权题库或原创补题许可 |
| 输出 | 最终细目表、学生卷、答案评分卷、题目索引、覆盖差额和检查记录 |
| 资源 | 可运行结构审计器、20 分合成示例及完整 JSON |
| 环境 | Python 3 标准库仅用于 JSON 检查；其他教学交付无需特定平台 |
| 限制 | 难度是预估；不能自动证明内容正确或来源授权真实 |

**调用示例**：使用 `$teacher-blueprint-exam`，按“等式变形 4 分、方程求解 6 分、情境建模 10 分”的蓝图组卷，允许原创，输出每题所属细目格与评分点分配。

**闭环**：约束核算 → 稳定细目格 → 选题或原创 → 分值分摊 → 目标/实际差额复核 → 完整试卷和索引。

**验收**：所有细目格差额为零；每题分配与评分分项分别等于题分；同一分不重复计入两个知识点；硬约束冲突没有被静默覆盖；受限原题没有进入公开资料。
