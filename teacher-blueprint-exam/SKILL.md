# 细目表组卷

交付能追溯到细目格的整套试卷。先把约束写成可核算的蓝图，再配置题目，最后用实际分值验证蓝图落实情况。

## 接收约束

输入可包含考试范围、总分、时长、细目表、题库和已获授权材料。细目表至少需要知识点、可观察能力、题型、预估难度和目标分值。用户没有细目表时依据其目标建立一张，说明假设后直接成卷；仅在用户明确要求“表审过才出卷”时暂停等待。

检查所有行列与总分一致。遇到互相矛盾的硬约束，给出冲突位置和最小调整选项，询问必须保留的约束；不要悄悄改总分或删除必考目标。对可满足的约束直接执行。题库不够时，可在允许原创的范围补写题并标为原创；要求全为真实原题时不得补写后假称真题。

## 组卷闭环

1. 给每个细目格一个稳定 ID。把“知识点”和“能力”分开写，例如“解一元一次方程”与“执行求解并检验”；“理解、掌握”等笼统词要具体到作答证据。
2. 从用户材料选题或独立编写题目。外部题保留来源定位、权限适用范围和答案核验状态；公开可访问不等于可复制公开。无明确使用权时仅交付来源链接与摘要，或按教学目标重新独立命题。用户明确指定先选题时遵守选题阶段，否则按约束完成整卷。
3. 每题分配到一个或多个细目格。分配依据评分点，分配之和必须等于该题分值。跨知识点题可分摊，但每题每一分只计一次；若题目各部分能力或难度不同，拆成子题分别登记。
4. 单独求解试卷并核对选项。客观题检查唯一正确选项、条件充分与数值自洽；开放题列接受范围。评分项对应可观察证据，分项和等于题分，相同证据不重复给分。
5. 汇总“目标分值、实际分值、差额、题号”的覆盖矩阵。差额不为零时替换、增减或重新分摊题目后复核；不得把缺口记为已完成。检查范围、总分、题型分值比例和预估用时。
6. 交付学生卷、答案评分卷、最终细目表、题目索引和核验记录。难度比例只作为预估记录，后续可用实际得分率修订，不声称已测量的难度或区分度。

## 独立可用的结构检查

本包内含 Python 3 标准库脚本和完整 JSON 示例，不依赖其他技能目录。进入本目录运行：

```bash
python3 scripts/audit_exam.py references/example-exam.json
python3 scripts/audit_exam.py /absolute/path/to/exam.json
```

JSON 要求见 [example-exam.json](references/example-exam.json)。脚本核对总分、题分、评分项、细目格维度、每题分配和每格目标。成功退出 0、错误退出 1，并返回错误路径。单选使用 `choice`，简答使用 `short_answer`，分步解答使用 `worked_response`；子题按独立题登记。

脚本不能判断题目的语义适配度、答案正确性、难度准确性、评分条件是否重叠或权限声明是否真实。审卷记录应注明实际做过的独立求解、逐项判断和来源核验，不能写“自动审题通过”。

## 交付要求

细目表和索引放教师材料，学生卷仅保留必要作答信息。引用班级结果制定蓝图时使用聚合数据，公开交付前移除真实学生信息及第三方受限试题全文。可直接照用的本包原创合成案例见 [worked-example.md](references/worked-example.md)，其中包含完整试题与可加总评分。
