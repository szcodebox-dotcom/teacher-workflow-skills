## 请求一：七年级10分钟12分小测

实际路由：`teacher-workflow-router → teacher-exam-builder`。请求指定3题及等式性质3分、解方程4分、生活应用5分，但未要求先审完整能力矩阵；由原创试卷流程建立内部覆盖表并直接完成，不停在确认关卡。

产物为 `request-1/student-paper.md`、`answers.md`、`scoring.md`、`coverage-and-review.md`、`exam.json` 与 `exam-audit.json`。学生卷不含答案；答案与逐步评分为独立文件。题面分别为等式两边同加4、求解 `3x−6=15`、购买两本同价手册及4元标签纸共22元。答案从题面重新计算并代入核对，Q2解为7、Q3单价为9元。评分给出可观察证据、替代解法、错误跟随处理和题分上限。

审计器实际返回 `ok: true`、3题、总分12、覆盖格3/4/5。逐题评分项与分配均合计题分；预估作答9分钟加检查1分钟。用时和难度是命题预估，未进行学生实测。题干为本次独立编写，没有复制格式例子的题面；未检索外部题库，因此不宣称证明全球不存在同构题。

## 请求二：四人得分到讲评与两周复测

实际路由：`teacher-workflow-router → teacher-learning-insights → teacher-class-action-plan`。先将请求转为规定六字段 CSV，再实际运行 `analyze_scores.py`，把原题及评分规则、JSON/Markdown报告、分母与缺失限制一起交给班级行动流程。年级沿用七年级数学，下一节默认40分钟；两周安排用 Day1–14相对窗口，没有假设真实校历。

| 核查项 | 实际结果与分母 |
|---|---|
| 数据量 | 8行：5行有效评分、3行空分；可见4人、2题、整卷10分 |
| 记录完整度 | 完整2人；部分1人；全未评分1人 |
| Q1/解方程 | 累计6/8=75%；有效2人，缺评分2人；覆盖8/16=50% |
| Q2/建模 | 累计13/18=72.22%；有效3人，缺评分1人；覆盖18/24=75% |
| 完整学生整卷统计 | S01=10、S02=5；均分15/2=7.5；整卷平均得分率75% |
| 通过、优秀 | 使用脚本默认60%、85%阈值，均为1/2=50%；分母不是4人 |
| 全部有效作答 | 19/26=73.08%，含S03已评分的Q2；不是全班平均得分率 |
| S03 | 只在Q2取得4/6，覆盖6/10=60%；Q1未补0，整卷得分率为null |
| S04 | 全未评分，得分为null；未归为零分、缺考或未掌握 |

JSON与Markdown数值一致。原分数没有步骤证据，因此没有把S02的2分/3分或S03的4分反推成某一个具体错因。知识点相差2.78个百分点且有效样本只有2/3人，只作核对线索，没有强行生成全班“最薄弱”诊断或固定学生群体标签。

`request-2`含原始CSV、`report/report.json`、`report/report.md`、证据及跟进表、40分钟下一节安排、可流动的A/B/C练习入口、Day1–14跟进表、逐点评分记录格式及说明。新题共有18题：当堂诊断、必要时使用的新补测、三个练习入口、出口检测、校准短测及两轮间隔复测，各2题。所有题均有完整题面、答案和逐点评分，解方程4分、建模6分；没有“再出一道类似题”的待补内容。撤提示、切换入口、补录或补测、未达标后的调整均有明确条件。

逐点记录格式预置240行评分项；得分留空表示尚未实施的未评分记录，不是虚构复测成绩。Day2补测使用新的P套，不回填原卷分数，也不把已经讲解的D题重做计为独立达标。报告明确新题的解释项核验细节与原“解释1分”无法证明严格等值，且不从描述差值推论干预效果。

## 实际检查与发现

- 成功执行原创试卷审计器及成绩分析器；用独立 `Fraction` 算式核对答案、代入结果与3/4/5分配。
- 核对学生卷无答案、答案与评分分离；逐项阅读新题答案；断言18题评分项完整且分数合计一致、课堂环节合计40分钟。
- 直接断言8行/5有效/3空分、2完整/1部分/1全未评分、7.5均分、Q1的6/8、Q2的13/18和总体19/26，确认S03/S04整卷分母未混入。
- 最小错误探针：重复键、越界分、同题满分不一致、全空分均退出2且未生成报告；有效零分可正常报告；无完整学生时整卷均分和通过率为null；完全缺行仍计入未评分题。试卷评分分项被刻意改错后，审计器退出1并报告失败。
- 两项交付脚本在本机完成语法编译；没有修改交付目录或生成其中的缓存。

发现的交付技能缺陷：本次未发现。独立模拟产物在人工审阅时曾出现题号表示不统一、补测复用已讲解题的问题，已在独立生成器中校正并复跑；它们属于本次生成过程，未归因为原技能缺陷。最终产物与断言均通过。

仍未验证的范围：真实学生的10分钟完成情况、课堂实施时长、题目难度、教学效果，以及模型在任意请求下的稳定遵从程度。机械脚本检查不证明学科质量；本次完整产物还包含代理按技能契约完成的学科求解与教学设计。
