# 备课与沟通组审核记录

审核日期：2026-10-14。范围：`lesson-pack`、`k12-lesson-design`、`office-kejian`、`yureka-lab-edu` 的原版能力与四个新版技能包。原版均只有一份短 `SKILL.md`；旧目录未由本组删除。

## 原版具体缺陷与升级

| 原版 | 原版发现 | 新版改法 |
|---|---|---|
| lesson-pack | 四类信息任何一项缺少都先等待；课件只给大纲，配图与排版交给教师补齐；缺少可教学样例、答案校验和次课复测 | `teacher-lesson-pack` 把内容歧义与可合理默认的缺项区分；一次交付完整五件套，贯穿 G 编号、页码、题号与退出题，附原创新题、全套答案和次课入口 |
| k12-lesson-design | 固定五环节但没有目标—活动—证据对应；自查只有勾选项，未定义可观察检查；无完成例题与实际时间案例 | `teacher-lesson-plan` 用检测倒推课堂路线，每段含学生动作、教师问题、证据与分支；40 分钟教案完整展示反例、板书、作业、答案与复测 |
| office-kejian | 明确规定大纲未经再次确认不得生成；无可运行生成器或格式依赖；没有实际 PPTX 与备注核验 | `teacher-slide-deck` 在用户要求成品时直接完成，保留用户明确要求先审大纲的路径；提供独立 JSON→PPTX 生成器、依赖、8 页内容源、实际课件与全页预览 |
| yureka-lab-edu | 触发范围混合备课与沟通；教研效果留空、缺少事例不写评语，容易交付空白或中断 | `teacher-communication-studio` 专注沟通；事实、推断与建议分开；无证据时生成完整行动稿或未实施提案，有事例时严格围绕输入，不虚构效果或稳定特质 |

四包均加入 `SUMMARY.md`、符合 UI 要求的 `agents/openai.yaml`、独立安装所需资源与原创完整 `references/worked-example.md`。新版文本为依据教学能力重新编写的表达，未复制网上技能或教材题。全部示例事件与数据明确标为合成情境；本次检查不等于对互联网所有文本的相似度证明。

## 实际验证

- 用系统 `skill-creator/scripts/quick_validate.py` 验证四包，四次输出均为 `Skill is valid!`。
- 实际解析四份 UI YAML：名称与目录匹配，版本为 `2.0.0`，`default_prompt` 含对应 `$skill-id`；四份简介长度分别为 29、29、31、29 个字符，均在 25–64 范围内。
- 人工复算完整五件套与教案的算式、对比单位和答案；平均数教案为 `3+7+9+7+8+4+2=40` 分钟，比较周长面积教案为 `4+8+10+10+5+3=40` 分钟。教研合成统计为 `12/24=50%` 与 `18/24=75%`，增加 6 人、25 个百分点，无因果效果断言。
- 使用 Python 3.12 与 python-pptx 1.0.2 实际生成 `teacher-slide-deck/assets/example-deck.pptx`；重新打开得到 8 页、8 份非空讲者备注、1 个可编辑表格。测试中实际修改标题和表格值，保存后重开保留修改；退出题答案只在备注，不在检测页正文。
- 运行 `python -m unittest discover -s tests -p test_slide_deck.py -v`：10 项通过。覆盖文件的页数/备注/比例/编辑重开、缺失备注、错列数、课时不一致、非法输入保留既有文件、过长内容、低于字符总上限但换行溢出的汉字内容、密集表格行高、非有限课时与超出栏标题框的换行内容。
- 本地 LibreOffice 将实际 PPTX 渲染为 8 页 PDF，再用 PyMuPDF 生成全页预览并查看。初次默认字体回退导致中文不可见，随后仅在临时目录设置字体配置，使用系统 Hiragino Sans GB 替代 Microsoft YaHei 渲染。第二次全部页中文显示完整，标题、双栏、表格、退出题与作业页未观察到溢出或遮挡。PPTX 同时明确设置拉丁和东亚字形字体名；未更改全局字体或打包字体。

## 限制与交付范围

换行估算是提前拒绝明显过密内容的边界，不能保证所有字体下同样排版；用户打开环境的中文字体仍影响最终版式。本例预览使用本地字体替代，未验证每一种 PowerPoint/WPS 平台。生成器处理简洁文字与表格，不实现动画、视频和复杂公式。五件套与教案示例是完整 Markdown 内容，未冒称已生成 DOCX。

没有用真实班级实施证明教学效果，也没有进行外部消息发送。本组只交付四个新版技能、审核记录与课件测试；GitHub 上传、全仓校验和长期记忆由总任务统一完成。
