# 学情、班级跟进与工具工作流审核

审核对象：原 `xueqing-analysis`、`class-analysis-junior`、`find-skills`、`skill-creator`。升级版本为2.0.0，使用teacher领域命名。说明、例子与代码重新撰写；旧目录不作为新包的执行依赖。

## 发现与升级

| 原技能 | 具体缺陷与影响 | 新技能与修正 |
|---|---|---|
| xueqing-analysis | 将成绩直接用于生成错因比例，缺少作答证据；未规定空分、重复记录、分母权重、不同满分试卷的可比性；没有实际计算工具 | teacher-learning-insights：分离数值事实/待验证问题；六列CSV契约；有效满分加权；完整/部分/全未评分分开；JSON与Markdown标准库脚本 |
| class-analysis-junior | 固定90/75/60分段没有试卷满分口径；凭得分给群体特征、主要错因；易错率与失分率含义不清；两周计划缺复测评分与调整条件 | teacher-class-action-plan：证据→讲评→可流动练习入口→Day1–14复测；人数、评分点、进入/切换条件明确；无题面不推断教学内容 |
| find-skills | 只有通用推荐步骤，没有准确技能映射；相近备课与命题任务无法可靠分开；组合步骤未传递输入输出与证据限制 | teacher-workflow-router：入口内置准确十二项映射；区分3种备课、3种命题、统计/订正/行动；逐步交接契约；不依赖根目录catalog |
| skill-creator | 要求固定3–5真实案例，案例不足就停止；只交付草稿；名称与系统通用技能冲突；没有独立包结构、界面配置及可检验的行为边界 | teacher-workflow-maker：完整技能包与必要摘要；真实案例可用时使用，不足用明确合成检查；teacher域命名；资源相对路径；验证类型与教学实测分开 |

四包均提供 `SKILL.md`、`SUMMARY.md`、`agents/openai.yaml`、完整合成工作例子。界面短描述分别28、25、28、28字符，默认提示词均含对应`$技能ID`。学情包另含数据契约、CSV和可运行脚本。

## 实际验证

2026-10-14运行：

```bash
python3 -B -m unittest discover -s tests -p test_learning_analysis.py -v
python3 teacher-learning-insights/scripts/analyze_scores.py teacher-learning-insights/examples/scores.csv --output-dir /tmp/teacher-learning-demo
```

19个行为测试全部通过，命令成功生成`report.json`与`report.md`。行为测试覆盖：

- 多人多题、不同满分的知识点加权分母；空分与有效零分；部分学生的缺行题目；零完整学生指标为null。
- 重复键、分值越界、无穷值/NaN、无知识点、同题满分/标签不一致、空数据/零有效评分和缺/重复表头的拒绝。
- UTF-8 BOM与小数；通过/优秀阈值的等号边界和错误配置。
- 不同卷满分分开报告；默认无跨卷差值；显式对齐声明只产生描述性共同知识点差值。
- CLI实际生成两种报告；错误输入退出码2且不创建报告目录。

四包分别使用系统skill-creator的`quick_validate.py`通过结构校验。该校验检查frontmatter、命名等结构项，不证明教学效果；资源相对路径另行核对。学情包复制到临时独立目录后，使用自身脚本与CSV运行`--aligned-exams`成功生成两种报告，得到E2通过人数1、共同知识点差值2项，无仓库根目录依赖。

样例计算复核：20行、有效14行、空分6行；E1完整2人、部分1人、全未评分1人。完整平均5.5/10、通过1/2；分数计算7/14=50%，应用表达9/12=75%，已评分作答16/26=61.54%。E2完整3人，满分12、通过阈值7.2分，只有10分学生通过，即1/3；平均23/3=7.666667。不同满分的原始总分不比较。声明对齐后共同知识点差值为+25与−16.666667个百分点，保留可比性限制。

班级示例核对：异分母加法题面、答案与四评分点一致，2/8得分率与1/2零分比例分开；讲评15分钟；Day3、Day7、Day14分别5、6、6分钟；练习及复测均有答案、评分点和调整条件。导航示例给出三步文件/证据交接与八种相近任务的主路由。封装示例给出四个完整文件与正常/未评分两种合成行为核对。

## 验证范围与保留限制

这里验证的是格式、数值与合成任务行为，未开展真实课堂试验，未宣称学生成绩提升。得分不能证明错因，空分不能确定缺考，CSV内完全没有行的学生/题目不可见。跨测验对齐由调用者声明，脚本不自动检测题目等值或干预效果；测验代号字典序不自动代表日期。

原创方式为独立撰写升级流程、示例和标准库脚本，保留通用技能格式惯例与学科事实；本审查不将有限范围检查描述为查遍全部网络或出版物。若后续引入教材/题库材料，应继续保留授权与来源信息，不能将来源抽取标成原创题目。
