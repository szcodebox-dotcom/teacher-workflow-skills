# 逐步评分规则（教师使用）

分项按可观察证据评分，不因结论正确自动补给全部过程分。等价的正确解法在对应同一目标的项目给分，每条最多给一次，各题不得超过题分。

Q1：仅写5x=20可得化简1分；只写x=4而无指定过程，得0分。写“移项、变号”不代替等式性质说明。运算和化简正确但缺依据得2分。

Q2：允许直接将两边同除3后再同加2等合法替代顺序；相应两个合法变形证据映射到前2分，正确解1分、原式检验1分。运算正确但算术错误时，已成立的步骤保留；后续沿错误中间式合法求解可给“求解步骤”这1分，但无正确x=7不得再另外加分。检验必须代入原式，若检验发现非解并明确指出不成立，可给检验1分；把不相等说成相等得0分。仅写x=7得1分。

Q3：2x=22−4等价列式同样可得建模2分；算术一步失误后沿其正确列式进行合法求解，求解项1分可跟随给分；错误建模后的正确代数运算不补建模分，求解项可得1分。解释项要求正确实际单价且代回实际总价。仅写“9元”不给设元、建模、求解分；若同时核对实际总价可得解释1分。没有新增证据不重复给分。合理的算术解法(22−4)÷2=9可映射至两项建模与求解共3分，未设元不给设元分；另附实际答句与核对可得解释分。

## Q1（上限3分）

| 可观察评分证据 | 分值 |
|---|---:|
| 完整写出两边同加4的运算式；只写“移项”而不展示两边操作不给这一分。 | 1 |
| 化简得到5x=20。 | 1 |
| 明确说明“等式两边同加一个数，所得等式仍相等”。 | 1 |

## Q2（上限4分）

| 可观察评分证据 | 分值 |
|---|---:|
| 展示两边同加6或等价的合法变形，运算两边都写清楚。 | 1 |
| 得到3x=21。 | 1 |
| 得到x=7。 | 1 |
| 将7代入原方程并说明左右两边同为15。 | 1 |

## Q3（上限5分）

| 可观察评分证据 | 分值 |
|---|---:|
| 设每本手册为x元，未知量含义、单位完整。 | 1 |
| 列式时用2x表示两本手册总价。 | 1 |
| 将标签纸4元与总付款22元正确纳入同一个等量关系2x+4=22或等价式。 | 1 |
| 正确求解得到x=9。 | 1 |
| 写“每本9元”，并以2×9+4=22核对结果符合题意。 | 1 |
