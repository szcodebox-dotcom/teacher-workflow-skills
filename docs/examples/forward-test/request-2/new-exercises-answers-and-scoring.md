# 全部新题答案与逐点评分

每道解方程题4分（两边减常数1、正确化简1、除系数求解1、原式检验1）；每道建模题6分（设未知1、列式2、求解2、解释1）。

等价正确解法映射到对应评分点，不重复给分。合法步骤但算术失误保留此前得分；后续沿错误中间结果正确运算，可给对应操作/求解分，但同一项最多一次。错误建模失去相应列式分，后续正确代数运算可得求解分。检验、解释须根据原式或实际情境，不因跟随错误而给错误结论分；检验明确发现不等可给检验操作分。仅有答案不给过程分。
