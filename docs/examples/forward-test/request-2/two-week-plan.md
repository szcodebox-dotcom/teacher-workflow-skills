复测可比性：原卷与D/P/E/Z/R1/R2均考查ax+b=c求解和“数量×单价+固定费用=总价”，解方程4分、建模6分，评分分配与原要求一致，数值/表述不同。本方案把解释项的可观察证据具体化为答句与实际总价核验；原题“解释1分”的细节未知，所以不声称严格评分等值。操作者须记录提示、时长、参与名单和缺失。先比较同一学生同一目标的完整评分点表现；名单、缺失变化或题目难度未等值时只描述，不说干预造成提升。原卷没有步骤记录，不反推其步骤变化；可从Day1起建立过程基线。提示练习不与无提示复测混算。

复测报告格式：每次分目标汇总“累计得分/有效满分、有效人数、可见人数、未评分数、满分人数/有效人数”；整卷指标只用完整记录者。Day14即使达标也仅限本次任务证据，不贴固定能力标签。
