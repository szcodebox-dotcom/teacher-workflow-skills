# 原创与来源记录

发布日期：2026-10-14。适用范围：本仓库 2.0.0 版发布文件。

## 新版创作范围

十二套技能的入口说明、摘要、教学示例、脚本、测试、仓库文档与三张信息图，均围绕用户提供的任务能力重新编写。设计采用“输入材料 → 执行判断 → 完整产物 → 验收与复测”主线，使用各任务特有的决策规则；没有把第三方现成技能改名后作为原创包发布。

示例中的课堂、学生代号、成绩、题目和沟通材料为明确标注的合成案例，不是学校实测数据。初版旧正文、旧海报、旧 ZIP 的权利来源未提供，因此不作为本仓库 MIT 授权对象，也不在发布压缩包中分发。初版内容仅保留 SHA-256 指纹，见 [baseline.json](audit/baseline.json)。

## 题目与图片

- 原创命题示例由本次任务编写，不声称来自中考、教材或官方题库。
- 有据题库只接收用户有权使用的材料或可核实且允许使用的来源。抽取题目不因此取得公开传播第三方全文的权限。
- 图文介绍使用代码绘制的信息图，SVG 和 PNG 同时提供；没有沿用初版海报、商业模板或外部图片。生成源码见 [build_visuals.py](../scripts/build_visuals.py)。
- 图片生成时使用本机已安装中文字体渲染，字体文件不随包分发。

## 检查范围

原始文件已备份到发布目录之外；新版与初版按对应技能进行文本相似片段检查，并对十二套新版入口之间的重复度做检查。结果及处理记录写入 [审核总表](AUDIT.md)。这种检查能发现机械复制或包内重复，不能证明全球所有未公开作品中不存在相似表述。一般教学方法、常见数学术语和标准 YAML 格式也不属于本项目独占创作。

本次检索原始标识 `lesson-pack`、`yureka-lab-edu`、`按组组卷` 与 `班级诊断 分段画像`，用于发现潜在来源线索；检索未提供足以确认初版授权链的证据。因此新版不依赖“检索不到便是原创”的推断，采用重写、排除旧素材和可检查创作记录的方式交付。
