# 十二套工作流审核与升级记录

版本：2.0.0。日期：2026-10-14。审核对象：用户提供的十二个初版 `SKILL.md`，以及本次独立重写的新版技能包。

## 审核结论

初版能描述教学任务，但多个工作流停在确认、建议或草稿阶段，缺少独立安装所需的资源和可检查示例。新版保留十二类能力，重建触发、输入处理、执行、完整产物与验收；取消没有依据的确认关卡，保留用户明确要求的分阶段确认。

## 逐套升级

| 工作流 | 初版问题 | 新版交付与验收 |
|---|---|---|
| 成套备课 | 缺一项必问，课件仅大纲，练习使用固定学生层级 | 五件套完整内容、答案、课时—页码—学案映射，按当堂表现选择练习 |
| 教案设计 | 固定五环节，目标与检测未形成一一对应 | 目标—活动—证据矩阵、总课时核算、课堂反馈分支与新题复测 |
| 可编辑课件 | 大纲强制停等，图片可为占位，缺实际生成路径 | 独立 PPTX 生成器、完整 JSON、逐页备注、可编辑表格、密度与有限值检查 |
| 原创试卷 | 必须先确认结构，题分与评分分项无机械核验 | 学生卷与答案卷、独立求解、来源声明、可加总评分和 JSON 审计器 |
| 细目表组卷 | 强制签字式定表，跨知识点分摊与差额未定义 | 细目格 ID、评分分值分摊、目标/实际/差额矩阵与独立审计器 |
| 有据题库 | 来源真实性与公开权限未说明，缺 OCR/答案缺失处理 | 材料台账、页码/原题号、许可范围、转录状态、原答案与推导答案区分 |
| 错题订正 | 批改颜色被直接当错误证据，巩固停在建议 | 观察事实/机制假设/验证问题、完整订正与变式、复测与未达标后续题 |
| 学情分析 | 分母、缺考、空分与题目加权未定义，错因比例易被猜测 | CSV 契约、有效作答加权、完整/部分/未评分区分、JSON 与报告、跨卷限制 |
| 班级跟进 | 仅按分数段推断群体特征与错因，缺练习和复测材料 | 证据表、讲评分钟表、完整弹性练习、答案评分和 Day 1–14 跟进 |
| 教学沟通 | 教研效果留空，材料默认含待补清单 | 有事实按事实写；无效果数据交付行动型成稿或明确尚未实施的提案 |
| 工作流导航 | 无实际能力清单，组合交接仅一句顺序 | 内置准确十二项映射、相近任务路由、输入输出与证据限制交接 |
| 工作流封装 | 强求 3–5 真实案例，只输出 v0.1 草稿 | 完整可安装包、正常与边界案例、合成验证明确标注，不冒充课堂实测 |

分组的原始发现与已运行检查见 [备课和沟通](audit/lesson-review.md)、[命题和错题](audit/exam-review.md)、[学情与导航](audit/analysis-review.md)。

## 已执行的验证

- **标准结构：** 十二套均通过 Codex `skill-creator` 的 `quick_validate.py`。名称与目录一致，版本 2.0.0，界面调用包含正确技能 ID；见 [标准校验记录](audit/skill-validation.json)。
- **行为测试：** 54 项通过：试卷结构 21 项、学情统计 19 项、PPTX 产物 10 项、本地安装 4 项。覆盖无效数据、缺分与零分、不可比试卷、总分/评分/细目格、可编辑内容与备注、文本密度、非有限用时、已有安装备份及符号链接保护。
- **独立安装：** 在临时目录安装全部十二套，分别从四个技能目录运行两个试卷审计器、学情分析和 PPTX 生成；全部退出成功，不依赖仓库根目录，未修改全局技能安装。见 [安装实跑记录](audit/standalone-installation.json)。
- **内容核算：** 两份命题示例均为三题二十分，细目格为 4/6/10；备课示例四十分路线可加总，练习与答案对应。学情 E2 的通过线为 12×60%=7.2，三名完整学生中只有一人达到，示例已纠正为 1/3。
- **课件视觉：** 实际生成八页 PPTX，包含八份讲者备注和可编辑表格；完整预览及局部字体处理见备课审核记录。自动结构通过不能替代逐页查看。
- **独立前向检验：** 使用全新十二分小测和一份含空分的成绩表执行任务，报告见 [独立复核](audit/independent-review.md)。完整产物见 [独立小测](examples/forward-test/request-1/student-paper.md) 与 [讲评跟进](examples/forward-test/request-2/two-week-plan.md)。这属于合成任务试跑。
- **原创重写检查：** 排除 YAML、代码与链接地址后，对十二个入口分别比对初版，并两两比对新版。未发现连续 24 字及以上的共有片段；最长初版共有片段为 12 字。见 [机器记录](audit/originality-check.json) 与 [原创范围](ORIGINALITY.md)。

## 验证的含义

这里的“通过”表示文件结构、脚本行为、示例计算和指定任务试跑已实际检查。它不证明所有新生成题的答案、第三方授权声明或真实课堂效果。技能入口因此要求答案核验、原件与许可留证、数据分母与缺失说明；不会把得分率当错因，也不会把合成案例写成教学成效。

## 可复现命令

```bash
python scripts/validate_repo.py --report output/repo-validation.json
python -m unittest discover -s tests -v
python scripts/install.py --dry-run
python scripts/build_release.py
```

运行环境和依赖安装见 [实操指南](QUICKSTART.md)。原创比对需要本地初版备份，因此不把初版正文分发给下载者；其 SHA-256 指纹记录在 `audit/baseline.json`。
