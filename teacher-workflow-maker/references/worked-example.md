# 完整例子：把离堂检测方法封装成技能包

这是合成封装用例，未使用真实学生数据，未宣称课堂效果。新生成的示例技能`teacher-exit-ticket-loop`是本例产物，不是十二套导航中的已安装第十三项。

## 输入

老师的方法：“最后3分钟让学生做一道有过程的小题，我按目标步骤记录，次日只反馈遗漏的步骤。没有作答就保留未评分。”目标是五年级数学异分母加法，要求结果为完整可复用包，不需要自动发布。

## 输出目录

```text
teacher-exit-ticket-loop/
  SKILL.md
  SUMMARY.md
  agents/openai.yaml
  references/example.md
```

流程不涉及反复计算或文件转换，无必要添加脚本。下面四个文件组成完整示例包。

### SKILL.md

```markdown
---
name: teacher-exit-ticket-loop
description: 为明确的学习目标制作三分钟离堂小题，并按作答步骤整理次日反馈；当老师需要课堂结束检测与次日跟进时使用。
metadata:
  version: "2.0.0"
---

# 离堂检测闭环

输入为学习目标、年级学科、已教内容、可用时长；整理结果时另需脱敏作答或评分点记录。只有总分时不推测具体遗漏步骤，没有作答时标为未评分。

围绕一个目标生成3分钟以内的完整小题、答案与逐点评分。题面应要求学生展示需观察的操作，避免正确答案掩盖过程缺失。把每个评分点作为记录列，同时保留总分与完整性状态。

读取学生作答后，逐点核对可见证据，输出目标、题面、答案、评分规则、记录表、次日反馈及再检测条件。无作答则只交付检测材料和空白可填写记录表，不编造已测人数或达标结果。

次日反馈选择尚未出现的步骤，再用不同数值、相同目标的小题检测。若该步骤在新作答中正确出现，可停止该步骤的重复练习；否则记录新证据并安排下一次支持。不使用固定学生能力标签。

数学示例与两个边界检查见[完整例子](references/example.md)。
```

### references/example.md

```markdown
# 合成例子与行为检查

目标：用共同分母解释异分母相加。题面：3分钟内计算1/2+1/3，写共同分母、两次等值变换及相加结果。
答案：共同分母6，3/6+2/6=5/6。
评分：共同分母1分；第一项等值变换1分；第二项等值变换1分；结果1分，共4分。评分要求过程，不能从只写正确结果反推其余3分。
记录列：student_id、common_denominator、equivalent_left、equivalent_right、sum_result、total_score、record_status、observed_steps。

正常检查输入：合成学生A01写“分母6，1/2=3/6，1/3=1/6，结果4/6”。
实际输出：评分点1、1、0、0，总分2/4；本题第二项等值变换与结果未达评分点。次日用六等分图核对1/3=2/6，再测1/3+1/6；答案2/6+1/6=3/6=1/2，四评分点各1分，未化简的3/6也得结果分。新作答四点全得则停止本步骤重复练习；否则保留新记录并追加图示支持。
核对结果：2/4与可见步骤一致，没有泛化为“计算能力差”。

边界检查输入：合成学生A02没有作答，只知道缺少评分记录。
实际输出：record_status=未评分，其余评分点和total_score为空，不计入0分；需要核对作答是否未录入或未完成，得到评分后再整理。产物仍含完整题目、答案、评分规则与可填写记录表。
核对结果：未伪造成绩或缺考原因，保留完成后续核对的入口。

这些检查只验证输入输出逻辑与数学自洽，不证明真实班级学习提升。
```
