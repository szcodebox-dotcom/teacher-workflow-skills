# 工作流封装 · 技能包摘要

**技能 ID：** `teacher-workflow-maker` · **版本：** 2.0.0

**解决的问题：** 有教学方法却缺少稳定的调用入口、输入输出契约、边界验证和独立安装文件。

| 项目 | 内容 |
|---|---|
| 触发 | 把教学方法做成skill、新建或升级教师工作流 |
| 输入 | 用途、现有流程或目标、输入输出、约束；真实案例有则使用 |
| 输出 | 完整技能目录、必要摘要、界面调用配置、实际验证记录 |
| 正文重点 | 触发准确、关键输入清楚、产物完整、边界有依据、资源可发现 |
| 验证 | 正常与关键边界的行为检查；有脚本则运行；合成验证明示不等于课堂实测 |
| 原创 | 自写说明、例子和代码，保留授权材料来源，不把抽取材料包装成原创 |
| 独立安装 | teacher域命名、相对包内路径、明确环境依赖，无作者机器路径依赖 |

**即用提示词：** 使用 `$teacher-workflow-maker` 将我的教学方法封装为完整技能包，写明输入输出与必要摘要，并用明确标注的案例实际验证。
