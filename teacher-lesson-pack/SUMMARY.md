# 成套备课 · 2.0.0

**用途：** 从一个课题一次配齐相互对应的教案、逐页课件内容、学案、课堂练习与作业。

**输入：** 年级、学科、课题；可补充课时、教材内容、前测结果、学校格式和设备条件。缺少班级数据时设计前测，不编造学情。

**输出：** 五件完整材料、教师答案、页码和题号对应关系、次课订正与复测安排。课件内容是完整逐页文案；文件格式按实际导出能力注明。

**闭环：** 学习目标 → 检测题 → 教学活动 → 五件材料 → 交叉核对 → 作业反馈与次课复测。

**依赖：** 核心内容不需外部服务；导出 Word 或 PPTX 时需相应文件生成工具。此包可独立安装。

**示例调用：** `用 $teacher-lesson-pack 为五年级数学“平均数”备一节 40 分钟课，一次给出可授课的五件套和教师答案。`

**内置示例：** [原创完整五件套与答案](references/worked-example.md)，全部情境数据为合成数据。
