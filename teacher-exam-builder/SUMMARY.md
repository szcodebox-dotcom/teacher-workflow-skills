# 原创试卷技能包摘要

**能力**：按范围独立编写新题，把答案、评分与题分覆盖一并交付。

| 项目 | 内容 |
|---|---|
| 适用任务 | 单元测验、随堂检测、新编课后练习 |
| 必要输入 | 学段、学科、知识点；已指定的总分、时长和题型限制 |
| 输出 | 学生卷、教师答案与评分规则、覆盖表、命题校验记录 |
| 边界 | 不把新编题称作真题；不承诺与全球已有题目绝对不相似 |
| 支持环境 | 能读写 Markdown 的助手；JSON 检查用 Python 3 标准库，无联网或账号要求 |
| 附带资源 | 完整 20 分原创示例、同内容 JSON、可运行结构审计脚本 |

**可直接使用的请求**：使用 `$teacher-exam-builder`，为七年级“解一元一次方程”编写 20 分、10 分钟原创测验，含 1 道单选题和 2 道解答题，交付学生卷、答案、分步评分和知识点覆盖表。

**闭环**：教学范围 → 分值结构 → 原创题 → 独立求解 → 评分与覆盖核验 → 分开交付学生卷和教师卷。

**验收**：题分、评分项与总分一致；单选答案经逐项判断唯一；开放题说明接受范围；范围内的知识点分值可追溯。审计脚本核对结构关系，学科答案仍需实际求解核验。
