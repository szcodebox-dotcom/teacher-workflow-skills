# 原创试卷

将教学范围变成一份能够独立作答、按规则评分的原创测验。原创指本次独立编写题干、情境、数据和解析，不表示常见知识点或数学结构从未出现过。

## 输入与决策

使用用户提供的年级、学科、知识点、总分、时长、题型、能力目标和限制。缺少非关键参数时给出明确且可修改的假设并完成交付；如果未说明学段或范围，且不同取值会改变可教内容，只问这一决定性信息。不得虚构教材页码、课程标准条文或“历年原题”出处。

有完整细目表时把它作为约束。有实际历史试题需求时先处理来源与使用权，不能把新编题标成真题。用户要求先审结构再命题时停在结构审阅点；其他请求直接完成结构、试题和校验，不设默认签字或逐步确认关卡。

## 生成与核验

1. 建立知识点 × 能力 × 题型 × 难度的分值表。标明每格目标分值、题号和实际分值；难度是命题预估，须用后续实测修正。把题分与考试总分、预计用时共同核对。
2. 为每格独立编写题目。题干说明条件、单位和作答要求；依赖图表时一并提供图表、必要文字与清晰标签。排除只换人名或数字却实质复制第三方题目的写法。
3. 不看拟定答案重新求解一次。单选题逐项判断，确认只有一个选项满足条件；计算题检查解存在、条件无矛盾、单位合理。开放题不要求答案唯一，列出满足条件的示例与等价表达接受范围。
4. 编写可加总的评分项。每个得分点描述可观察证据，分项合计等于题分；同一证据不重复给分。说明正确替代解法、后续步骤跟随错误的处理和该题上限，避免仅写“酌情给分”。
5. 逐题核对范围、图表、答案与评分项。在覆盖表中按实际评分点分摊分值；一题考查多个知识点时不能给每个知识点重复计整题分。列出任何尚未解决的实质疑点，受影响题不进入可直接使用的学生卷。
6. 试卷转成 JSON 时，参照本目录 [example-exam.json](references/example-exam.json) 后运行下面的本地审计器。完成后提供学生卷、教师卷、覆盖表和检查结果；不要用结构检查通过代替学科审题。

## 机械检查

仅需 Python 3 标准库。进入本技能目录执行：

```bash
python3 scripts/audit_exam.py references/example-exam.json
python3 scripts/audit_exam.py /absolute/path/to/exam.json
```

返回 JSON 报告，成功退出码为 0，失败为 1。检查题号、选项重复、答案字段、题分/评分分项/细目格分配/总分、知识点范围、来源声明字段和覆盖匹配。JSON 模型的 `choice` 是单选；其他题型用 `short_answer` 或 `worked_response`。每题必须有非空答案、正分值评分项和分配；细目格必须全部满足。

此脚本不能证明单选在语义上只有一个正确选项、答案正确、评分项无语义重叠、难度真实或来源权利有效。这些要通过独立求解和人工可审阅的核验记录处理。

## 交付

- 学生卷：卷头、说明、连续题号、分值、完整材料；不混入答案。
- 教师卷：逐题答案、解法、评分项、可接受替代表达及适用的部分得分规则。
- 命题记录：输入与假设、覆盖矩阵、预估用时、原创声明、校验结果及未解决事项。

教学示例见 [worked-example.md](references/worked-example.md)。只在需要学习交付粒度时读取；它是本包合成示例，不是真实考试或学生数据。面向学生的文件移除真实姓名、班级名单和分析标签。正式考试交付可审阅版本，并说明学科核验范围；不得宣称自动校验保证试题科学性。
