# 教学沟通

把已知事实、专业解释和下一步行动分清，使沟通对象知道怎样配合、何时反馈。用户要成稿时直接交付可复制或朗读的全文。

## 输入与事实账本

最低输入是沟通体裁、对象与主题。可选输入包括年级、学科、篇幅、语气、真实事件、已核对统计、现有安排。

先在工作记录中列“已提供事实 / 尚无证据 / 本次建议”。统计需保留人数、分母、时间和原口径；证据冲突时只报告可核对部分，不自行补数。个人材料尽量使用用户给的学号或化名，公开分享版去除识别信息。

- **家长会：** 无班级数据也能完成“这次希望共同完成什么、家庭怎样做、学校怎样跟进、何时反馈”的行动稿；不能写成已有成绩提升。
- **教研：** 有实施记录则写记录和限制；尚未实施时写教学改进提案与观察方案，标题和正文表明尚待实施，不能填虚构效果或空白“待补数据”。
- **学生评语：** 有真实事件就围绕事件写；没有事件时写面向该阶段学习任务的鼓励和具体建议，不写该学生已经表现出的特质。个人性格、心理或诊断判断不从片段事件推出。
- 缺少对象或主题会改变内容时集中询问；其他缺项用明示的适用范围完成可用版本，不留姓名、日期、数据占位。

## 制作流程

1. 选定体裁和读者，保留用户的目的、语气与长度。讲稿按正常朗读估算时长并注明是估算；评语按用户字数收紧。
2. 每项事实都能回到输入；区分“观察到一次行为”与“稳定特点”。没有材料支撑的判断删除或改成建议。
3. 完成正文：
   - 家长会写共同目标、已知信息或本次范围、2–3 个家庭动作、教师跟进、反馈时间与方式。
   - 教研材料写具体问题、设计理由、操作过程、实际证据与局限，或未实施提案的采集计划和判定方式。
   - 评语写有证据的事件或不含事实断言的学习建议，再写一个可操作的下一步。
4. 给动作加闭环：谁执行、做什么、何时检查、怎样反馈。用“下一次课堂”或“随后一周”可形成实际安排；没有用户授权不承诺学校未提供的服务或具体教师行为，可表述为本次建议方案。
5. 做事实与语气检查：删除羞辱、公开排名、疾病标签、未经授权的私人信息；将建议阈值和预计效果表述为计划，而非结果。
6. 交付成稿，附简短事实核对表与实际使用说明。交付不等于发送或发布；仅在用户明确要求发送并给定渠道与受众时使用发送工具。

## 验收

- 正文无空白槽位、编造案例、虚构进步或缺分母的百分比。
- 每个行动有执行者、期限或检查节点及反馈方式。
- 有证据与无证据模式的文字都能直接使用，后者不冒充个体化评价或实证教研报告。
- 对个人材料只用必要信息；教师内部记录与公开发布版按实际受众分别处理。

需要了解两种证据模式时，读取 [原创沟通成稿示例](references/worked-example.md)，其中事件和数据均为明确标注的合成示例，不得当真实案例发布。
