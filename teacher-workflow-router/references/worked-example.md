# 完整例子：测验后讲评与家长会沟通

这是合成教学导航案例，材料与数字均为设计用例，不是课堂实测。

## 任务

用户要“五年级数学测验分析、两周跟进方案、5分钟家长会稿”。已有材料：六列脱敏成绩长表；Q2题面`1/2+1/3`与4分评分点；每次检测可用时长；学校允许公开聚合统计，不允许公开学生明细。两周内依次可用15分钟、5分钟、6分钟和6分钟。

## 完成的路由工单

主起点是 `teacher-learning-insights`。顺序为：

```text
脱敏得分长表
  → teacher-learning-insights：核口径、分卷报告
  → teacher-class-action-plan：讲评、练习与两周复测
  → teacher-communication-studio：5分钟家长会稿
```

不启动备课或命题工作流：用户要的是现有测验的后续跟进与沟通，练习由行动计划围绕评分点生成即可。若后来明确需要一套全新单元试卷，再按命题约束单独路由。

| 步骤 | 输入与必需信息 | 输出对象 | 验收条件 |
|---|---|---|---|
| 学情分析 | CSV六列完整；空分保留；同题满分/知识点一致 | report.json、report.md、数据限制 | 每个得分率能找到分子分母；完整/部分/未评分人数分开；不从成绩生成错因 |
| 班级跟进 | 上述报告；Q2题面及四评分点；五年级数学目标；15/5/6/6分钟窗口 | 讲评表、弹性练习答案评分、Day1–14表、复测字段 | 每次有责任人/用时/任务/检查条件；练习按当天步骤证据流动；缺分不当零分 |
| 教学沟通 | 聚合证据、限制、已安排的行动；沟通目的；5分钟与公开边界 | 完整家长会文字稿、可展示的聚合表 | 不含学生明细/排名；计划用将来表述；未测得的成效不写成已发生事实 |

## 证据交接示范

示例Q2记录为S01得2/4、S02得0/4、S03/S04未评分。交接给下游的统计句是：“Q2有效2人，累计2/8=25%，另2人未评分。样本小，先核对并观察四评分步骤。”

不能写“75%的全班学生不会通分”：75%是失分率，不是答错人数比例；题目只有2个有效记录；没有对应作答支持“不会通分”。

行动交接为：“Day1独立重做后按四点评分，选择前置/完整/迁移练习；Day3、Day7同评分点复测；Day14加入情境表达。数据缺失继续单列。”这段可以进入家长会稿作为待实施安排，不能写“已经提高25%”。

## 可直接调用的交接提示词

1. 使用 `$teacher-learning-insights` 分析所附六列CSV；保留空分与零分差异，输出JSON及Markdown，并交出Q2有效人数、分子分母和缺失限制。
2. 使用 `$teacher-class-action-plan` 读取上述报告和Q2题面/四评分点，按15、5、6、6分钟窗口完成Day1–14讲评、弹性练习、复测及调整条件。
3. 使用 `$teacher-communication-studio` 根据聚合报告和待实施方案写完整5分钟家长会稿；不披露学生明细，不把未来计划写成已验证成效。
