# 工作流导航 · 技能包摘要

**技能 ID：** `teacher-workflow-router` · **版本：** 2.0.0

**解决的问题：** 备课、命题、学情任务看似相近，容易选错主技能、重复生成内容或丢失交接证据。

| 项目 | 内容 |
|---|---|
| 触发 | 这个任务用哪套技能、怎样组合十二套工作流 |
| 输入 | 目标产物、教学任务、已有材料；需要时补充年级学科 |
| 输出 | 主技能匹配、关键缺口、顺序、输入输出与验收契约 |
| 内置映射 | 三个备课、三个命题、三个学情、一个沟通、两个工具工作流，共十二项 |
| 关键区分 | 成套备课/单教案/PPTX；原创命题/细目表组卷/材料题库；统计/错题/班级行动 |
| 独立安装 | 完整十二项映射写在SKILL.md，无根目录catalog依赖；其他技能未安装时明确执行状态 |
| 验证状态 | 包内合成任务验证路由和交接逻辑，未宣称真实课堂效果 |

**即用提示词：** 使用 `$teacher-workflow-router` 根据我的目标产物与已有材料，选择这十二套工作流中的主技能，给出关键缺口、顺序与每步验收条件。
