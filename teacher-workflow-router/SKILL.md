# 工作流导航

围绕老师要拿到的产物选工作流，不凭关键词同时启动多个相近技能。本技能内置下面的十二项能力映射，独立安装也可给出精确建议，不需要读取仓库根目录的索引。

## 内置能力映射

| 技能 ID | 主产物与启动条件 | 必要交接输入 | 易混边界 |
|---|---|---|---|
| `teacher-lesson-pack` | 要一次交付教案、逐页课件内容、学案、练习与作业的成套备课 | 年级学科、课题/教材内容、课时、教学目标或范围 | 成套内容与单份教案不同；可编辑PPTX交给课件技能 |
| `teacher-lesson-plan` | 只需能授课的教案，重点对齐目标、活动与检测 | 课题、课时、学习起点、目标/教材范围 | 不因出现“备课”就生成全套配套材料 |
| `teacher-slide-deck` | 把教学内容制作成可编辑PPTX与讲者备注 | 已有内容/教案、受众、讲授时长、文件样式需求 | PPTX文件制作与整套教学设计分开；只有图片不能冒充可编辑课件 |
| `teacher-exam-builder` | 给定考试范围后从零原创题目、答案和评分 | 年级学科、范围、总分、时长、题型/难度约束 | 没有细目表时可创建一般原创试卷；不负责材料溯源题库 |
| `teacher-blueprint-exam` | 按知识点×能力细目表组卷并检查覆盖 | 明确细目表或需要先建立细目表的范围、分值/题量目标 | 用户明确强调矩阵覆盖时优先于一般原创命题 |
| `teacher-source-question-bank` | 从获授权材料提取题目并留来源、页码和核验状态 | 授权材料、题目范围、来源信息/页码 | 来源抽取保留来源属性，不能改名声称原创试题 |
| `teacher-mistake-coach` | 针对具体错题完成识别、订正、变式和复测 | 题面、学生作答、正确答案或可验证解法 | 一道题的订正不等于全班统计；无作答不推断个人错因 |
| `teacher-learning-insights` | 统一得分口径，交付知识点统计与数据限制 | 脱敏小题得分、满分、知识点、测验标识 | 统计报告与后续讲评日程分开；总分不能拆成小题 |
| `teacher-class-action-plan` | 将证据转成讲评、弹性练习、两周复测 | 可核查学情证据、题目/评分规则、教学范围、可用课时 | 行动计划不从分数推出错因；练习入口不成为固定学生标签 |
| `teacher-communication-studio` | 根据真实证据生成家长会稿、教研材料或学生评语 | 沟通对象、目的、真实证据、可公开范围、文体/时长 | 宣讲与学情计算分开；没有真实证据就不写成绩提升等事实 |
| `teacher-workflow-router` | 交付任务匹配、顺序、输入缺口与交接契约 | 教学任务和希望拿到的产物、已有材料 | 只要求选择时交付导航；实际执行需加载目标技能或明确可用替代能力 |
| `teacher-workflow-maker` | 把可复用教学方法封装成完整可安装技能包 | 用途、可执行流程或样例、输入输出、约束 | 不是安装第三方技能的工具；合成验证不能冒充课堂实测 |

## 选择与执行

1. 从用户要求提取目标产物与现有材料。一项任务通常有一个主工作流；只有产物或输入转换不同才串联。比如“给我一份教案”选教案，“教案学案作业都要”选成套备课，“已有教案做PPTX”选课件。
2. 命题先看来源与覆盖约束：指定材料抽取选有据题库；指定知识点/能力矩阵选细目表组卷；按范围原创试卷选原创试卷。提取题库接着组卷时必须保留各题来源状态，不把串联后的抽取题称原创。
3. 学情任务先区分统计、个人订正与班级行动。成绩长表先学情分析，作答错题先错题订正，已有报告需两周安排直接班级跟进。成绩和题目缺失只能完成现有证据支持的部分。
4. 给每个交接定义：输入文件/对象、必需字段、输出文件/对象、验收条件及证据限制。下游必须收到这些内容，而非只收到一句“继续处理”。
5. 用户只问推荐时交付完整导航。用户请求执行时，定位并读取目标技能后完成授权范围内的产物；若未安装，指出该项是建议而非已调用，并在具备能力时采用等价流程交付。外部发布、消息发送或安装不能由导航建议扩大授权。

## 导航产物

给出“目标产物 → 主工作流 → 已有输入 → 关键缺口 → 执行顺序 → 各交接与验收”。不列无关备选。关键缺项会改变题目、事实或分母时一次列明；格式、页数和相对日程等可合理默认，并把默认值写入导航。

完整合成范例见 [从测验到跟进与沟通](references/worked-example.md)。导航中的技能 ID 应与上表完全一致，不能使用旧通用名称替代，也不能虚构第十三个已存在的技能。
